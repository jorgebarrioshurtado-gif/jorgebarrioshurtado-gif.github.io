WhatToWatch

A personalised film recommender built by integrating 4 data sources (MovieLens 32M, IMDb, TMDB API, Bechdel Test) into a normalised MySQL database covering 70,000+ films. Users get recommendations filtered by mood, genre, decade, and Bechdel score, powered by PCA (150 components, ~80% variance explained) and KMeans clustering (150 clusters). Includes a deployed Streamlit app with real-time poster retrieval and three Tableau dashboards on gender representation and genre patterns.

Python MySQL KMeans PCA Streamlit Tableau TMDB API
GitHub ↗

Vanguard A/B Test

End-to-end analysis of a real Vanguard digital experiment testing a redesigned client interface. Cleaned and merged 4 raw datasets (755,000+ rows) into a 317,000-row analysis-ready dataset, defined conversion KPIs, and ran hypothesis testing that confirmed a statistically significant 13.6 pp uplift in completion rate. Results were presented in an executive-ready Tableau dashboard.

Python Pandas SQL Hypothesis Testing Tableau
GitHub ↗

IBM Attrition Analysis

Designed and managed a relational SQL database of IBM HR records, structuring schemas to support efficient querying of employee demographics, performance, and attrition data. Queried and analysed 1,400+ employee records to identify attrition drivers including compensation bands, work-life balance scores, and career progression rates. Delivered structured analytical reports translating SQL findings into actionable HR recommendations.

SQL MySQL Python Pandas Data Modelling

Sustainable or Staged?

An investigation into greenwashing in fast fashion. Merged multi-source ESG datasets to cross-analyse environmental KPIs against sustainability claims across 15+ brands, then used EDA and comparative Matplotlib visualisations to surface the gap between what brands report and what the data shows.

Python Pandas EDA Matplotlib Seaborn

Forest Cover Type Prediction
